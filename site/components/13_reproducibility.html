Data Availability & Reproducibility

The Temporal Equivalence Principle (TEP) is an open-science framework. All mathematical derivations, data processing pipelines, and empirical analyses discussed in this capstone synthesis are fully available in the specialized repositories of the TEP Series.

The TEP-HUB Routing Directory

The analytical conclusions presented in this manuscript are supported by the following open-source codebases and datasets:

  • The Bi-Metric Derivations: Formal tensor calculus defining the coupling of the matter Lagrangian to the temporal gradient and the derivation of the Observable Response Coefficient ($\kappa$) are available in the TEP-HC repository.
  • Dark Sector Replacements: The Lense-Thirring-analog derivation of Temporal Shear ($\Gamma_t$) as the mechanism flattening galactic rotation curves is provided in TEP-GL.
  • The Chronometric Pipeline: The full Python/C++ pipeline used to extract synchronization holonomies from the 25-year CODE Precise Clock Products, including the strict baseline exclusion filtering protocols, is open-sourced via the TEP-GNSS repository.

Researchers are actively encouraged to clone these repositories, audit the algorithms, and re-run the Bayesian inference models against standard $\Lambda$CDM baseline assumptions. Complete replication instructions and environment configurations are provided in each respective repository.
